iRMSD matching pipeline

How one pairwise comparison in get_irmsd gets from two sets of coordinates to an atom assignment and an RMSD: rank setup, min_rmsd, and the bond-preserving selection added on top of it.

0. What a get_irmsd call decides

Users pass two structures and nothing else. The only setting, iinversion, defaults to auto everywhere (API, ASE and RDKit wrappers, CLI). Every branch below is decided by the code from the structures themselves.

  1. 1Cluster rule. A small solute in many waters counts as a cluster, so the walk is skipped and the solute can keep a bond-breaking LSAP mapping. Walking each sizeable fragment and leaving only small identical ones to the LSAP would close this.
  2. 2Bonds from coordination numbers. Stretched geometries (transition states, weakly bound metal complexes) can give the two structures different bond graphs. The ranks then do not reconcile, and the call drops to element types or a plain RMSD with only a warning.
  3. 3Mirror decision from the reference. Auto mode tries the mirror image only when the reference has no stereocentre, which is the CREST convention for comparing conformers.

1. One comparison end to end

The ranks decide which atoms may be swapped at all; min_rmsd finds an orientation and an assignment within those ranks; refine_assignment makes sure the final assignment keeps every bond and is as low as the walk can get it.

2. Atom ranks

Two atoms may only be exchanged if they share a rank. Ranks come from user-supplied IDs or from the canonical sorter; a second structure with the same element order and bonds simply copies the first one's ranks.

3. min_rmsd

The branch point is the number of atoms with a unique rank. Three or more of them pin the orientation directly; otherwise the principal axes of inertia do, with up to 32 candidate orientations because the axes carry sign and degeneracy ambiguities. In both branches each rank group is assigned by an LSAP on squared distances, independently of bonds.

4. Bond-preserving selection

min_rmsd can return an assignment that maps a bonded pair onto a non-bonded one, which makes the RMSD look lower than any real correspondence. The selection compares it with the centre walk and keeps the lowest RMSD among candidates that preserve every bond. Bonds are checked after the terminal-atom refinement, because that step repairs H atoms swapped between parents.

5. Centre walk

The walk builds a correspondence that preserves bonds by construction: it only ever extends along a bond. Choices are made by distance as soon as the matched atoms fix a frame; before that, every possibility is enumerated. Each complete start is polished by alternating a Kabsch fit with a re-walk in that frame, and the best start gets a local search over single choices, which is what finds ring flips and methyl swaps whose benefit only shows in the total RMSD.

Flat toy molecules run through a Python transcription of the same steps, so every number shown is computed for these coordinates. Because the molecules are flat, the mirror test changes nothing and the four 180-degree turns of min_rmsd become flips in the plane. H atoms are left out.
